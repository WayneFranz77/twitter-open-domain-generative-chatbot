# Twitter Open-Domain Generative Chatbot

A deep learning chatbot trained on Twitter conversations using Natural Language Processing (NLP) and Sequence-to-Sequence models.

## Features

- Data preprocessing and cleaning
- Text tokenization
- Model training and evaluation
- Interactive chatbot interface

## Installation

pip install -r requirements.txt

## Training

python src/training_model.py

## Run Chatbot

python src/chat.py
